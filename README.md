# ⚡ The One-Person Agency Launchkit

A starkly minimalist, cinematic, step-by-step technical guide and boilerplate for Indian freelancers and agency owners to automate client intake, onboarding, bookings, and secure UPI payment gateways.

### 🌐 Live Production Deployment
[![Vercel Deployment](https://img.shields.io/badge/Deployment-Live%20on%20Vercel-success?style=for-the-badge&logo=vercel&color=000000&logoColor=ffffff)](https://one-person-agency-launchkit.vercel.app)

---

## 🚀 Key Features

- **Conversion-Optimized Landing Page**: Minimalist, problem-first landing page crafted with custom responsive touch targets and premium micro-interactions.
- **Interactive ROI Calculator**: Built-in state-driven client calculator to analyze operational friction and intake ROI in real-time.
- **AI Intake Consultant**: Preconfigured server-side chat interface orchestrating secure AI-driven agency recommendations.
- **Robust Mobile Layout**: Strict defensive guardrails preventing viewport zoom or overflow layout breakage.

## 🛠️ Tech Stack

- **Core**: Next.js (App Router), React, Turbopack
- **Styling**: Tailwind CSS (CSS-First tokens, modern Squircle layouts)
- **Deployment**: Vercel

## 💻 Getting Started

### Local Development

1. **Clone the repository and install dependencies**:
   ```bash
   git clone https://github.com/sangan007/agent-launchkit.git
   cd agent-launchkit
   npm install
   ```

2. **Run the local dev server**:
   ```bash
   npm run dev
   ```

3. Open **[http://localhost:3000](http://localhost:3000)** in your browser to view the application.
